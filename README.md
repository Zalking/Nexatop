# NexaTop UI — Vue 3 + Vite

Frontend NexaTop dibuat di atas folder Vite yang kamu kirim. Aset artwork game dan ilustrasi hero disimpan lokal di `src/assets/` sebagai SVG, sehingga tidak membutuhkan URL gambar eksternal.

## Menjalankan project
1. Ekstrak folder project.
2. Buka terminal di folder `nexatop-ui`.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka URL lokal dari Vite yang muncul di terminal.

## Fitur prototype
- Katalog 8 game dengan artwork lokal dan pencarian.
- Pilih nominal dan ringkasan harga.
- Form User ID, Zone/Server ID, nama, kontak.
- Upload bukti transfer dan pratinjau gambar.
- Daftar pesanan tersimpan di localStorage.
- Dashboard admin demo untuk melihat bukti dan mengubah status pesanan.
- Layout responsif untuk desktop dan mobile.

## Catatan
Ini frontend prototype. Data disimpan pada browser, belum ada backend/API, autentikasi admin, database, atau payment gateway. Informasi rekening yang ditampilkan adalah contoh ilustrasi, bukan rekening nyata.
